この調査について

発端は、Pi Network のモデレーター間で共有された「アカウントに勝手に署名鍵が追加され、しきい値（後述）が引き上げられて、本人が締め出される」という主張である。本調査は、その主張をチェーン上の記録で検証するために、鍵が追加された記録（signer_created、エフェクトの type_i 10）の全件を数え、追加を受けたアカウントについて侵害の「兆候」を集計したものである。

用語

  • 署名鍵の追加（signer_created）：アカウントに署名鍵が追加された記録。追加された鍵がアカウント自身と同一のものは、アカウント作成・移行時の本人登録であり、どのアカウントにもちょうど1回だけ現れる。2回目以降の追加は、本人以外の鍵が足されたことを意味する（ただし後述の留保がある）。
  • 重み（weight）：鍵ごとのポイント。本人の元の鍵（マスターキー）の重みは通常1。
  • しきい値（threshold）：操作に必要なポイントの合計。low＝軽い設定変更、med＝送金、high＝鍵の追加・削除など鍵そのものの管理、の3段階。通常はすべて0で、本人の鍵（1点）だけで何でもできる。たとえば「1/2/2」は low=1・med=2・high=2 を表し、この場合、本人の鍵だけでは送金も鍵の削除もできない。一方、重み1の鍵がもう1つあれば 1＋1＝2点となり、両方を持つ側はすべて操作できる。
  • ロック（ロックアップ）：移行時に一定期間送金できなくなる残高。解除時刻は、エフェクト（type_i 51）の条件（rel_before 秒）から復元できる。

本レポートの数値はすべて侵害の「兆候」の集計であり、盗難の断定ではない。また、第三者の鍵の追加それ自体も侵害の証明にはならない。Pi の Developer Portal でメインネットアプリを作成する際、提供された署名鍵（マルチシグ）を追加する正規の手続きが存在したためである。個々のアカウントの事情はチェーン外の情報なしには判断できない。

きっかけとなった実例

アカウント GDR67Y7GIHHHSFH74SKO2KAUKB4AV5XAY4ACNLHUXV4KZCVBSXIZOJIB では、2026-06-05T17:32:16Z に鍵 GBLY27C6YKMLKDYOY7UUXP5FKGTI4GTFPOSNBQOMOAZOYK5CSWYIAWAG（重み1）が追加され、同じ取引の中でしきい値が 1/2/2 に引き上げられた（本人登録は2024-01-06）。本人の鍵（重み1）だけでは med・high の2点に届かず、送金も鍵の削除もできない形である。この鍵は、後の第5部の照合でも再び現れる。

考察 — 「締め出して解除を待つ」モデルとの照合

本調査の出発点には、次の見立てがあった。攻撃者はパスフレーズを盗んだうえで鍵を追加し、しきい値を引き上げて本人を締め出す。本人（重み1）だけでは解除後の資金にも触れられないが、攻撃者は本人の鍵と追加鍵の合計2点で送金できる。狙いは追加時点の流動残高ではなく、ロックされた残高が解除される日である。

  • この見立てと整合する点：締め出しはほぼ全件（97.1%）で成立していた。追加時点の残高はほぼ空だったのに、流出額は大きかった。流出は追加直後ではなく解除直後に集中し、過半数が3分未満だった。鍵の追加は1日に集中し、使い回しの鍵プールと共通の送金先インフラが見えた。
  • 単純には説明できない点：締め出されていないアカウントほど流出の割合が高かった（43%）。また、解除済みでも無事なアカウントが多数（63,198件）あり、追加＝即流出ではない。解除から7日以上経っての流出も 2,649 件ある。
  • 未解決の点：未解除の 37,585 件について、解除の時期に何が起きるかはこれからしか分からない。本調査はここまでの結果をまとめたもので、その後の追跡は未定である。

限界と注意

  • 本レポートは侵害の「兆候」の集計であり、盗難の断定でも、個人の特定でもない。チェーンの記録は資金の移動を示すだけで、操作した人物は示さない。
  • 第三者の鍵の追加には、Developer Portal でのアプリ作成に伴う正規のマルチシグ登録という説明が成り立つ場合がある。ただし、その平常時の実績は年あたり数件規模であり、2026-06-05 の 128,653 件という集中は別物である。
  • 残高の再現が信頼できたのは 110,650 件中 84,671 件（76.5%）であり、残高に依存する判定はその範囲に限られる。割合は全体とSubsetの両方を併記した。
  • Phase 2c の設定は 2026-11-05 時点の姿（スナップショット）であり、その後に変更された可能性は含まない。
  • 全数調査の範囲は 2026-11-01T09:59:30Z まで。以後の追加・送金は含まない（Phase 2c の現在設定を除く）。
  • 取引所のラベルは第三者の調査報告・報道に基づく。流出額には通常の売却等が混ざる可能性がある。
