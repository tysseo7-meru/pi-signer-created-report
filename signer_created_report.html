signer_created 全件調査 ― 第三者に鍵を追加されたアカウントの追跡と検証（プロジェクトNo.3）

本レポートは、AIアシスタント「モコ」（モデル: Muse Spark 1.3、提供: Meta）が、Pi Network のオンチェーン記録（Horizon API が公開するエフェクト・取引の履歴）だけを用いて行った調査の記録である。推測で個人を特定するものではなく、チェーン上に残された事実の集計である。

対象範囲：Pi メインネットの創世から 2026-11-01T09:59:30Z（台帳番号 29,518,771）まで。

調査の概要

2026年6月5日前後に、自分のアカウントに知らない鍵が追加され、操作できなくなった（マルチシグ化された）という被害が複数あった。これがどの程度の規模で起きているのか、また、その後も同様の追加が続いているのかを、チェーンの記録から検証するのが本調査である。

検証の進め方は次の通りである。まず、ネットワーク全体の記録から「鍵が追加された出来事」（signer_created）を全件集める。次に、本人の登録ではない追加（第三者による追加）を受けたアカウントを全て追跡し、(1) 追加の後に送金があったか、(2) 本人が締め出された状態になっているか、(3) ロックされた残高の解除と送金のタイミングがどう重なるか、を集計する。

用語

signer_created（サイナー・クリエイテッド）は、ブロックチェーンの記録の種類のひとつで、「アカウントに署名用の鍵が追加された」出来事を表す。アカウントには複数の鍵を登録でき、各鍵には「重み」（点数）が付く。操作には種類ごとに「しきい値」（必要な点数）が決まっており、軽い変更用（low）、送金用（med）、鍵や設定の管理用（high）の3段階がある。たとえば本人の鍵の重みが1で送金のしきい値が2なら、本人の鍵だけでは送金できない。これを本レポートでは「締め出し」と呼ぶ。アカウントが作られるときには、本人の鍵が自動で登録され（これも signer_created として記録される）、これを「本人登録」と呼ぶ。それ以外の追加が「第三者による追加」である。移行（マイグレーション）で受け取った Pi の一部は一定期間ロックされ、期間が終わると「解除」されて使えるようになる。

実例アカウント

発端となった報告の対象アカウント GDR67Y7GIHHHSFH74SKO2KAUKB4AV5XAY4ACNLHUXV4KZCVBSXIZOJIB では、2026-06-05T17:32:16Z に鍵 GBLY27C6YKMLKDYOY7UUXP5FKGTI4GTFPOSNBQOMOAZOYK5CSWYIAWAG（重み1）が追加され、同じ取引の中でしきい値が low 1 / med 2 / high 2 に引き上げられた。本人の鍵（重み1）だけでは送金も設定変更もできない形である。このアカウントの本人登録は 2024-01-06 にあり、追加はそれとは別の出来事だった。

注意：第三者による鍵の追加それ自体は、侵害の証明ではない。たとえば Pi の開発者ポータルでメインネットのアプリを作成する際には、指定された鍵を追加する手順が通常の作業として存在したことが確認されている。本レポートは出来事の集計（兆候）を示すものであり、個別のアカウントについて侵害があったかどうかを断定するものではない。

考察

本調査で検証する作業仮説は次のようなものである。攻撃者はパスフレーズを盗んだアカウントに自分の鍵を追加し、しきい値を引き上げて本人を締め出す。本人だけでは送金も鍵の削除もできない。一方、攻撃者は本人の鍵と追加した鍵を合わせれば操作できる。狙いは手元の残高ではなく、ロックされていて今は動かせない残高であり、それが解除される日を待つ。

この仮説が正しければ、「締め出されたアカウントが、ロックの解除直後に送金する」という姿が観察されるはずである。本調査の結果はその予測と一致する。締め出し状態のまま解除後に送金したアカウントは 17,351 件あり、うち 10,426 件は解除から3分未満の送金だった。また、追加後の送金の大半が7日以上後だったことも、その場で抜くのではなく解除を待つという仮説の側に合う。もっとも、これは予測との一致であって、個別のアカウントについての証明ではない。

追加の作業そのものについても、第1部の通り、鍵のプールの共有、活動の窓の一致、ペアでの同時追加といった、単一の組織的な作業をうかがわせる形跡がある。

限界

送金は、金額や送金後の残高を問わず数えている。「解除された後に送金があった」は「抜かれた」と同義ではない。

締め出し状態でないアカウントの送金には、本人の操作が含まれうる。本レポートでは該当する数を分けて示した。

「まだ解除されていない」の件数は、判定の基準時刻（2026-11-05T04:22:50Z）時点のもので、時間の経過とともに減っていく。

ロック解除の時刻は、エフェクトの請求条件に記録された期間からの復元である。

全件調査の範囲は 2026-11-01T09:59:30Z までである。追跡に使ったアカウント情報の取得は 2026-11-03〜05 で、それ以降の変化は含まない。

取引所ウォレットなどのラベルは、第三者の報告や報道に基づくもので、各取引所の公式な公表ではない。

調査の経緯

本レポートは、当初は残高の条件（送金後に残高が 2 Pi 以下になるか）を含む集計で公開したが、2026-11-05 にその条件を使わない構成に作り替えた。残高の推移を履歴から組み立て直す方法では、組み立てが実際と一致するか検証できたアカウントが全体の76.5%にとどまったことが、作り替えの理由のひとつである。なお、第2部（2）の締め出しの内訳は、異なる時点で取得した2つの設定値の集計でも、鍵の残存 110,622 件を含めて一致している。
